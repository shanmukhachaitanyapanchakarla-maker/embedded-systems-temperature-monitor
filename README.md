# Introduction to Embedded Systems & IoT Device Design

## Smart Temperature Monitoring System

This project was developed as part of an Embedded Systems & IoT learning task.

The project demonstrates a Smart Temperature Monitoring System using Arduino UNO and TMP36 temperature sensor. The system continuously monitors surrounding temperature and activates an LED alert when the temperature exceeds a predefined threshold value.

---

## Features

- Real-time temperature monitoring
- Temperature display in Celsius and Fahrenheit
- LED alert indication
- Sensor interfacing using Arduino UNO
- Embedded systems and IoT concepts

---

## Components Used

- Arduino UNO
- TMP36 Temperature Sensor
- LED
- Resistor
- Breadboard
- Jumper Wires

---

## Software Used

- Arduino IDE
- Tinkercad Circuits
